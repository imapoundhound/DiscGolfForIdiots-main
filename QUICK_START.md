## 🆘 TROUBLESHOOTING

### Android Studio won't open?
```powershell
$studioExe = "C:\Program Files\Android\Android Studio\bin\studio64.exe"
$projectPath = "r:\AppBuilds\source\DiscGolfForIdiots\DiscGolfForIdiots-main\android"
Start-Process -FilePath $studioExe -ArgumentList $projectPath
```

### Android build fails?
- Check `android/local.properties` has: `sdk.dir=R:\installerpkgs\Android\sdk`
- Run: `flutter doctor` - should show all green
- Check SDK Manager in Android Studio

### GitHub Actions failing?
- Check workflow logs: GitHub → Actions → Click failed job → View logs
- Common issues: Missing paths, permission errors, build tool versions
- Click "Run workflow" to retry with same code

### APK won't install on phone?
- Make sure phone allows "Install from Unknown Sources"
- Check minimum Android version matches your device
- See `android/app/build.gradle` - `minSdk 21` means Android 5.0+
